# Computer Vision (Računalni vid)

Laboratory exercises and implementations for the **Computer Vision** course at the **University of Zagreb, Faculty of Electrical Engineering and Computing (FER)**.

**Academic year:** 2026/2027  
**Semester:** Winter  
**ECTS:** 5  
**Course instructors:** Tomislav Hrkać, Zoran Kalafatić

## Course Overview

The course covers fundamental and deep learning-based methods in computer vision, including:

- Geometric image transformations
- Edge and corner detection
- Scale-space keypoint detection
- Motion analysis
- Convolutional neural networks for image classification
- Object detection and semantic segmentation
- Generative image models
- Attention-based models

## Laboratory Exercises

This repository contains implementations and solutions for the course laboratory exercises, covering:

- Geometric transformations
- Edge and corner detection
- Object detection
- Normalizing flows
